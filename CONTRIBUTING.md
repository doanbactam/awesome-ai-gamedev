# Contributing

Thanks for helping build Awesome AI Game Development.

## Scope

Submit useful resources for game development, especially references that help developers design, build, evaluate, or ship games with AI assistance. General game development resources are welcome when they clearly support this goal.

## Requirements

- Submit resources you have reviewed, not automatically generated bulk link dumps.
- Prefer authoritative documentation, practical guides, visual references, open-source projects, and working examples.
- Use the original, canonical URL when possible. Avoid affiliate links.
- Explain what each resource offers in one factual, concise sentence.
- Avoid duplicate, broken, misleading, or purely promotional links.
- Disclose your affiliation if you maintain or represent a submitted resource.
- Link to a resource; do not copy its content or images without permission.

## Formatting

- Put resources under the most relevant existing category.
- Keep top-level categories in **A–Z alphabetical order**.
- Keep entries within each category in **A–Z alphabetical order**, ignoring case.
- Format entries as: `- [Resource name](https://example.com/) - Short, objective description.`
- Use the official project or product name. Do not alter names solely to affect their sort order.
- Propose new categories only when the existing categories do not fit.

## Pull requests

Open one focused pull request with a brief explanation of the changes. Check spelling, links, descriptions, category placement, and alphabetical order before submitting.
